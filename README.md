
# WoW-Market

A free World of Warcraft: Forever addon for vendor
information, item searches, merchant locations and
auction house price comparisons.

## Development Status

Alpha 0.0.7 – Under development

## Features

- Minimap button
- Vendor and item search
- Merchant locations
- Auction house price comparisons
- Wowhead reference links
- Transparent data source information
